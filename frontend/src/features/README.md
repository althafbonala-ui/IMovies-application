# Features Directory (Redux Toolkit State Management)

Contains Redux state slices and store setup for **iMovies Application**:
- `store.js`: Central Redux store combining all reducers.
- `auth/authSlice.js`: Manages user login state, JWT token, user role.
- `movies/movieSlice.js`: Manages fetched movies, active filters, search queries.
- `booking/bookingSlice.js`: Manages selected cinema, showtime, selected seats, and running total price.
