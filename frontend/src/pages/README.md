# Pages Directory

This directory contains route-level page views for **iMovies Application**:
- `HomePage.jsx`: Featured movies hero carousel, now showing, upcoming releases.
- `MoviesPage.jsx`: Filterable movie catalog (genre, language, rating).
- `MovieDetailsPage.jsx`: Movie synopsis, cast, trailer, and showtime listings.
- `SeatSelectionPage.jsx`: Interactive cinema hall layout for picking seats.
- `CheckoutPage.jsx`: Order review, ticket price summary, and payment simulation.
- `BookingSuccessPage.jsx`: Booking confirmation with QR code / ticket reference.
- `LoginPage.jsx` & `RegisterPage.jsx`: User authentication forms.
- `UserProfilePage.jsx`: User booking history and profile details.
- `AdminDashboardPage.jsx`: Cinema manager portal (add movies, create showtimes).
