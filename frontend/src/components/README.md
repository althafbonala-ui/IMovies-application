# Components Directory

This directory contains modular, reusable UI components for **iMovies Application**:
- `Navbar.jsx`: Global navigation bar with branding, movie search, auth buttons.
- `Footer.jsx`: Global footer with copyright and quick links.
- `MovieCard.jsx`: Displays movie poster, title, genre, rating, and "Book Tickets" CTA.
- `SeatGrid.jsx`: Interactive cinema seat selection matrix (Screen, VIP, Premium, Standard).
- `BookingSummaryModal.jsx`: Modal popup displaying chosen seats, pricing, and checkout confirmation.
- `LoadingSpinner.jsx`: Reusable loading indicator.
- `ProtectedRoute.jsx`: Client-side route guard enforcing authentication.
